🔗 Integrasi Google Drive
Belum terhubung ke Google Drive.
Cara mendapatkan Client ID:
1. Buka console.cloud.google.com → buat project baru.
2. Aktifkan Google Drive API (APIs & Services → Library).
3. Buat kredensial → OAuth client ID → tipe Web application.
4. Tambahkan domain tempat file ini di-hosting ke Authorized JavaScript origins (harus https:// atau http://localhost — tidak bisa file:// lokal).
5. Tempel Client ID di atas, klik Hubungkan, lalu login & izinkan akses.
Aplikasi hanya meminta izin drive.file — hanya bisa mengakses file yang dibuat aplikasi ini, tidak bisa membaca file Drive lain.

Stress & Exercise
HRR₁ = HRpeak − HR pada 1 menit recovery. Referensi: ≤12 bpm abnormal pada standard exercise dengan cool-down; ≤18 bpm pada protokol abrupt-stop/stress-echo. Cutoff bergantung pada metode dan protokol. *Bukan batas universal.
